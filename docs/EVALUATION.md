## Fix acceptance rate

Measured inside the app, per rule, on Guideline Health: accepted or lightly edited (30% or less changed) over everything decided, with the last decision on a finding winning, so an Undo counts. It lives in each browser's workspace, so a number only exists where people have used the app; any figure reported for this project says how many decisions it comes from and whose they were.
